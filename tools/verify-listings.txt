# Cross-site manual verification corpus — 3 Vrbo + 3 Airbnb, spliced
# alternating so a verification pass exercises both adapters back to back
# and site-registry's resolution has to switch sites on every hop.
#
# Separate from live-listings.txt on purpose: that file is Vrbo-only and
# drives the tools/live-check.js CDP runner. This one is a hand-verification
# manifest (open each in a real, human-driven Chrome profile with the
# unpacked extension loaded from src/) — Vrbo's PerimeterX and Airbnb's
# DataDome both hard-block automated/--load-extension sessions, so there is
# deliberately no script that walks this list.
#
# Vrbo picks: chosen for ROUTE-SHAPE coverage, the only axis distinguishable
# offline (no captured Vrbo payloads exist in this repo). Each exercises a
# different branch of site-registry's tiered getPropertyId extraction.
#
# Airbnb picks: chosen from measured extraction output across all 6 captures
# in airbnb_listings/ (walked-item counts and resolved policy fields below
# are real, not estimated).
